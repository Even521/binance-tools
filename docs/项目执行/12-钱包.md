# EVM 靓号钱包生成

在桌面应用“工具”菜单后提供“钱包 > EVM 钱包生成”。用户配置 Ethereum 地址靓号规则后，程序在本机搜索命中钱包，并展示地址、12 个助记词、私钥和完整派生路径。

钱包生成是独立 Rust package，UI 通过本地依赖调用。生成结果不保存、不导出、不发送到网络。

## 范围

- 支持前缀、后缀、包含三种匹配。目标是地址 `0x` 后的十六进制字符，大小写不敏感，默认前缀，长度 1–40。
- 页面提供 CPU / GPU 选择、开始、停止、尝试次数、每秒速度和命中结果。
- CPU 始终可用。GPU 只在构建包含 CUDA 后端且本机有可用 NVIDIA 设备时启用。
- 命中后展示 ETH 地址、BIP39 英文 12 词助记词、64 位十六进制私钥和派生路径，并可以隐藏或再次显示。私钥不带 `0x`，方便导入 MetaMask；复制按钮只在用户点击时复制。
- 搜索在后台运行。重复启动会被阻止；停止、离开页面或关闭窗口时取消搜索。
- 助记词和私钥不得写入日志、配置、数据库、普通文件或错误消息。

## 模块

| 路径 | 职责 |
| --- | --- |
| `crates/evm-wallet/` | 独立库，不依赖 GPUI。生成助记词、派生密钥、匹配地址、执行可取消搜索。 |
| `crates/evm-wallet/src/pattern.rs` | 校验并匹配前缀、后缀、包含规则。 |
| `crates/evm-wallet/src/generator.rs` | CPU / GPU 搜索、EIP-55 地址和钱包材料。 |
| `crates/evm-wallet/src/cuda.rs` | CUDA 可用性、设备名、批次上限和搜索桥接。未启用 `cuda` feature 时固定不可用。 |
| `crates/evm-wallet/cuda/` | 可选 CUDA 后端，按 Pascal `sm_61` 构建。 |
| `crates/evm-wallet/build.rs` | 仅在启用 `cuda` feature 时调用 CUDA 12.6 的 `nvcc`。 |
| `examples/desktop-gpui/src/ui/wallet_generator.rs` | 输入、CPU / GPU 选择、后台任务、进度和结果展示。 |
| `examples/desktop-gpui/src/ui/title_bar.rs`、`dashboard.rs`、`ui/mod.rs` | “钱包”菜单、`OpenWalletGenerator` 和页面导航。 |

依赖为 `bip39`、`bitcoin` 的 BIP-32 / secp256k1、RustCrypto `sha3::Keccak256` 和 `zeroize`。不自制密码学原语。

## 搜索

派生路径为 `m/44'/60'/0'/0/{index}`。助记词是 BIP39 English 12 词，种子口令为空。地址由未压缩 secp256k1 公钥做 Keccak-256 得到，展示时使用 EIP-55 校验和。

- CPU：每个助记词从 index 0 连续检查 1024 个地址，然后换新助记词。
- GPU：CPU 生成助记词并派生到 `m/44'/60'/0'/0`。GPU 只接收该分支的扩展公钥、chain code、目标和 index 范围，按最多 131072 个地址一批并行搜索非 hardened 子索引。同一助记词会连续搜索，直到非 hardened index 用完才换助记词。
- GPU 只回传命中 index。CPU 用同一扩展私钥重新派生 `m/44'/60'/0'/0/{index}`，重算地址并核对规则，通过后才把钱包材料交给 UI。
- 停止搜索时，取消在当前批次结束后生效。取消和错误不返回部分秘密。

GPU 设备端根据公钥 Y 坐标奇偶位恢复 BIP-32 压缩父公钥，执行 HMAC-SHA512、`IL * G + parent_pubkey`、Keccak-256 和地址匹配。零标量、不小于曲线阶的 tweak、以及无法转成仿射坐标的点会在设备端丢弃。

命中路径不一定是 `/0`。导入 MetaMask 时：

- 路径最后是 `/0`：导入 12 个助记词后，第一个账户就是这个地址。
- 路径最后不是 `/0`：导入页面上的私钥，地址一定一致；只导入助记词时，需要加到对应账户序号。

## 页面

默认使用 CPU。GPU 不可用时按钮禁用，并显示“当前程序未包含 CUDA 后端”或“没有可用的 CUDA 设备”。设备可用时显示显卡名称。

搜索中显示当前后端、已尝试地址数和每秒速度。状态、进度和错误不包含助记词、私钥或 xpub。离开页面时取消 worker，并清掉页面持有的结果。

## 安全

- 随机数来自操作系统。BIP-32 和椭圆曲线运算使用 bitcoin crate / libsecp256k1。地址哈希必须是 Keccak-256，不能换成 NIST SHA3-256。
- 助记词、BIP-39 seed、扩展私钥和普通私钥只留在 CPU。CUDA 后端不能接触这些数据。
- 助记词和私钥字符串在结果释放时清零。BIP-32 临时私钥离开作用域时调用 secp256k1 的清除接口。
- GPU 返回的 index 必须由 CPU 独立复算。index 超出本批范围，或复算地址不匹配规则，都返回固定错误，不展示该结果。
- 输入错误、线程启动失败、派生失败、CUDA 失败和用户取消分别显示，错误文本不带密钥内容。

## 构建和运行

CPU 版不依赖 CUDA：

```powershell
cargo run -p desktop-gpui
```

GPU 版需要 CUDA Toolkit 12.6，目标架构是 GTX 1070 的 Pascal `sm_61`。CUDA 13.x 不能生成该架构，构建脚本会拒绝 13 及以上主版本。12.6 可与现有 CUDA 13.3 并存，不覆盖驱动。

```powershell
$env:CUDA_PATH_V12_6 = "E:\app\cuda-12.6.2"
cargo run -p desktop-gpui --features cuda
```

`desktop-gpui` 的 `cuda` feature 转发到 `evm-wallet/cuda`。构建脚本使用 `-gencode=arch=compute_61,code=sm_61`，链接 CUDA Runtime，并把 `cudart64_12.dll` 复制到 exe 同目录。安装脚本在该 DLL 存在时一并打包。

当前开发机驱动 560.94 满足 CUDA 12.6 的 Windows 最低要求。参考 [Pascal 支持矩阵](https://docs.nvidia.com/datacenter/tesla/drivers/cuda-toolkit-driver-and-architecture-matrix.html) 和 [CUDA 12.6 驱动要求](https://docs.nvidia.com/cuda/archive/12.6.0/cuda-toolkit-release-notes/index.html)。

## 接口

- `MatchMode::{Prefix, Suffix, Contains}`。
- `VanityPattern::new(mode, target)`：校验并保存小写目标。`matches` 去掉 `0x` 后按规则比较。
- `SearchBackend::{Cpu, Cuda}`。
- `search_vanity(...)`：固定走 CPU。
- `search_vanity_with_backend(pattern, backend, is_cancelled, on_progress)`：返回 `Found(WalletMaterial)` 或 `Cancelled`。
- `WalletMaterial { address, mnemonic, private_key, derivation_path }`。
- CUDA C ABI：`evm_wallet_cuda_available`、`evm_wallet_cuda_max_batch`、`evm_wallet_cuda_device_name`、`evm_wallet_cuda_search`。搜索返回 `1` 表示命中，`0` 表示本批无命中，负数表示参数、分配或 kernel 错误。只有返回 `1` 时读取命中 index。

## 实现记录

CPU 搜索、GPUI 页面和“钱包”菜单已接入。CUDA 后端已实现，并且只在 `--features cuda` 下编译。

GPU 搜索复用设备缓冲区，避免每批重新分配显存。单批上限是 131072 个地址，用来占满 Pascal GPU；取消仍在批次之间检查。

## 验证

- 前缀、后缀、包含规则，以及空目标、非十六进制和超长目标。
- BIP39 助记词、派生路径、私钥和 EIP-55 地址来自同一次派生。
- GPU index 与 CPU BIP-32 结果一致；越界或复算不匹配的 GPU 返回值不会显示。
- 停止、离开页面和窗口关闭会取消 worker。进度和错误不包含秘密。
- 未编译 CUDA、没有 NVIDIA 设备或 CUDA 初始化失败时，CPU 模式仍可使用。

2026-10-15 在 GTX 1070 上用 CUDA Toolkit 12.6.2（`E:\app\cuda-12.6.2`）验证：HMAC-SHA512 向量、8 组确定性父密钥的 index 0/17 对照、三种匹配规则，以及随机助记词 GPU 命中后的 CPU 复算均通过。CUDA 13.3 不能生成 `sm_61` 内核。
